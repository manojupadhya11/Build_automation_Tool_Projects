Project API

The browser dashboard and external clients use the same project data and validation rules.

GET/api/projects

List projects. Optional query params: search, status, category, difficulty.

GET/api/projects/:id

Fetch one project by ID.

POST/api/projects

Create a project with validation.

PUT/api/projects/:id

Replace editable project fields.

DELETE/api/projects/:id

Delete a project permanently.

GET/api/stats

Dashboard metrics and grouped status/category counts.

GET/health

Application health endpoint.

EXAMPLES

Try it with curl

curl http://localhost:3000/api/projects

curl "http://localhost:3000/api/projects?status=Active"

curl -X POST http://localhost:3000/api/projects \
  -H "Content-Type: application/json" \
  -d '{
    "title":"GitOps Production Platform",
    "category":"GitOps",
    "difficulty":"Advanced",
    "status":"Planned",
    "owner":"DevOps Shack",
    "description":"Build a production GitOps workflow using Argo CD.",
    "repository_url":"https://github.com/jaiswaladi246"
  }'
