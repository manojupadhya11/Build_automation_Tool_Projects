Project API

Use these endpoints to manage the same project records shown in the browser dashboard.

GET/api/projects

List projects. Supports search, status, category and difficulty filters.

GET/api/projects/:id

Get one project.

POST/api/projects

Create a project.

PUT/api/projects/:id

Update a project.

DELETE/api/projects/:id

Delete a project.

GET/api/stats

Dashboard metrics.

GET/health

Application health check.

EXAMPLE

Read projects

curl http://localhost:5000/api/projects
